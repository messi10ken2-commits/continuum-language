# Continuum World Tokyo — 人物・植栽・店先の追加仕上げ

2026年11月26日。公開済み `02505f9` を基準に、Phase 2へ進む前の追加改修。本変更は本番未反映。既存の自由移動、施設、コンパニオン選択、保存位置、Photo／Illustration／Light、Learning Memory・授業・課金・DB構造を維持する。

## 変更

- 人物は球・円柱主体の形状から、顔・目・指・髪・50以上の関節を持つ、同梱のスキニング済み3Dへ置き換える。QuaterniusのCC0 Standard版を確認し、必要な部分だけを使用。シャツ・袖・襟・パンツ・靴・旅行者のバックパックは独立した衣服の形状として制作。服を素肌へ着色するだけの表現にはしない。
- 男女2種類を使用し、街・室内で共有する。1種類につき一度取得・解析し、人物ごとに独立したスケルトンを複製する。衣服を同材質でまとめ、人物の描画を最大8プリミティブへ抑える。合計約3.8MB、1体約1.1〜1.3万三角形。
- 非同期の任意アート読込であり、取得失敗時も従来の人物で探索を続ける。退出後の取得は中断し、解析が遅れて完了した場合も、表示せずGPU資源とImageBitmapを破棄する。画質切替・再入場でアカウントをまたぐ人物キャッシュは持たない。
- 樹木は曲がりを持つ幹、太枝・細枝・根張り、枝先に沿った楕円体状の葉群へ変更。葉は茎と葉脈のある独自Canvas素材。Auto／Lowでも昼だけ木漏れ日の軽量投影を表示し、夜には消す。
- 店舗は窓ごとの庇と支柱、ガラスの手前・奥に重ねた商品棚、鉢植え、窓際のカップ、縦長の商品案内、暖色の奥壁・照明を追加。看板は1枚のアトラスと結合メッシュでまとめ、テナントごとの表示を維持しながら描画を削減する。地上の追加小物は既存の建物の敷地内に置き、入口の前と通路を確保する。
- 5つの公開アートファイルだけに、既存のnative-origin向けCORSを適用する。対象は既存JPEG3枚と人物GLB2体。資格情報は許可せず、manifestや他の静的ファイル・APIの許可を広げない。

## 検証と受け入れ

- GLBのハッシュ、自己完結性、衣服、スケルトン、三角形・プリミティブ・取得容量の上限を検証。
- モデル取得失敗、中断、退出後の解析完了、二重破棄、独立スケルトン、座標維持、reduced motionを検証。
- 既存の移動・衝突・保存・施設・実タッチ・バックグラウンド・WebGL復旧・言語・別アカウント・フラグOFFの操作QAを継続。
- 昼／夜／Medium／カフェ／マーケット、PC／スマホ幅で実描画し、写真と人物の読み込み、コンパニオンの画角、GPUエラーを検証する。全9場面で人物の解析完了を待ってから撮影する。
- 実アプリ＋隔離DBで、通常のPractice入口、施設入退場、退出、Photo復帰、進捗未変更、5ファイルのnative CORSを検証する。
- アーキテクチャ単体の上限は125描画・52,000三角形。人物・動物・影などを含む全シーンの実測とは区別する。実機30fpsを保証する数字ではない。

確定コミットのCIと実測値はPRとそのArtifactsを参照する。スクリーンショットは合成の検証用シーンで、実ユーザーデータを含まない。

## 残る範囲

今回指定された3点を、コード・同梱アセット・失敗時処理・テストを含むレビュー可能な追加改修として仕上げる。参考ゲームと同等のフォトリアル品質、実在の渋谷の正確な再現を達成したとは扱わない。高品質な都市一式の専用アート制作とは規模が異なる。

iPhone実機のFPS・発熱・ピークメモリ・VoiceOver、およびMac/Xcodeでのコンパイルは未検証。NPC自由会話・ミッション・継続記憶などPhase 2の追加は行わない。本番への追加反映は別途承認後に行う。
