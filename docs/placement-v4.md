# Rounded placement, v4

All four learning languages use four rotating forms with 45 scored questions
(15 reading, 15 language use, 15 listening) and two separately reviewed
productive responses. The length and existing production workflow are retained.
Each difficulty band contains one grammar, one vocabulary and one pragmatic
response task. The scored domains are interleaved within each band.

The release includes 160 new vocabulary/response items, 16 refreshed A2 grammar
items (including ongoing actions and past habits), and 16 practical listening
clips/questions. Each form contains just one contextual colloquial expression
at B1; specialised regional slang and isolated trivia are excluded. Missing that
one expression does not prevent progressing if the other evidence is sufficient.
Examples and scenarios are held out from the lesson question bank. Vocabulary
and response situations vary across all four forms, not only option order.

V4 course placement requires 2/3 in reading, 2/3 in language use and 2/3 in
listening at each consecutive band from A1. Separate reading, listening and
language-use profiles remain visible, with a 5-item grammar/vocabulary/pragmatics
breakdown. Speaking and writing remain separately reviewed evidence; neither
is silently treated as an automatically established CEFR proficiency level.
These thresholds are editorial and provisional, not psychometrically calibrated
or statistically equated across forms/languages. V1–v3 scoring is unchanged.

Saved active tests retain their version and exact questions. Completed history
is preserved. Only newly created sessions use v4. All scoring, answer keys and
ownership checks remain server-side. The display-only translation corpus has
no answer indices or item IDs. Instruction translation preserves target-language
contexts and quotes; language-use answer choices stay in the target language.
Comprehension options can use the learner's display language.

Checks: `npm run test:placement`, `npm run test:placement:browser`.
Tests use disposable local data, not live accounts or paid audio/AI calls.
