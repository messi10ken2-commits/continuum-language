# Worldwide passport scenery

The replacement collection has 53 destinations, listed in public/passport-scenery/destinations.json. Six nine-panel illustration atlases provide the scenes; the final atlas uses eight panels. These are AI-generated interpretations inspired by real locations, not documentary photographs. UI labels describe them as illustrated landscapes.

Existing chapter achievement IDs determine stable scenery assignments. Existing earned dates and requirements remain unchanged. Special return/rhythm stamps retain the original art. Companion finale keepsakes remain separate. Across the four languages, chapter artwork cycles through the 53 destinations; an image is not an additional achievement or evidence that a learner travelled.

Source prompt: edge-to-edge 3×3 grid, equal square panels in destination reading order, no gutters/text/logos/people/animals; refined realistic hand-painted gouache/watercolor travel scenery, natural light, muted jewel colors, postcard style. Built-in image generation was used.

Real-photo update: `passport-cards.mjs` prioritizes the reviewed Commons collection and existing regional photos. The 53 generated scenes are retained as fallback assets; see passport-real-photos.md.
