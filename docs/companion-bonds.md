# Approved companions and bond rewards

Bird, fox and cat now use painted, independently positioned head/body/tail assets matching the approved design review. Bird also has an articulated wing; fox and cat have alternate happy eyes. The art manifest records original generated source names and output hashes. Existing vector placeholders have been replaced in the map, chooser and journey hub. Parts are prepared by scripts/prepare-companion-art.cjs using the retained source sheets; no image service is needed at runtime.

Each language has a separate bond record for each companion. The first synchronization grants all three companions credit for already completed chapters, preserving existing achievement without requiring repetition. Thereafter each newly observed completed chapter credits the selected companion exactly once. Credits are transactional and persist after switching companions, logging out or changing devices. Repeating a chapter does not farm credit. Account deletion cascades through these records. Breaks never reduce a bond.

Rewards: 2 chapters unlock a greeting; 5 unlock tap-to-play animal audio; 10 unlock a delighted reaction. The 5-second journey celebration is independently unlocked by a saved exercise-source pass on that language's basic Learn C1 final summary test, using the authored pass mark (currently 85). Placement assessments, Practice Studio results, imported attempts and repeated low scores do not satisfy this condition. Existing valid C1 summary passes qualify. Rewards can be replayed, do not block learning, and respect reduced-motion preferences. Sound never autoplays, stops when leaving/changing companion, and has explicit loading/error handling.

Audio recordings are locally hosted excerpts, converted to mono AAC with reduced loudness. Full author, source, change description and license links appear in the reward panel and public/companions-v2/audio-credits.json. Cat: Dan Crosby, CC BY-SA 3.0. Byte-range and HEAD responses support audio seeking on mobile browsers.
