# Dedicated additional-language worlds

Chinese, Korean, French, German, Arabic and Italian use six independently generated panoramic illustrations, rather than a renamed original-language scene. The scenes draw on Jiangnan canal architecture, a Korean station/hanok district, French limestone riverside buildings, a German half-timbered railway town, a North African Arabic-speaking courtyard district, and an Italian piazza. These are illustrative neighbourhoods, not claims to represent every country or dialect.

Built-in image generation produced the six scene assets in public/country-worlds/{zh,ko,fr,de,ar,it}/panorama.webp. Prompts specified a continuous wide elevated miniature neighbourhood, station at left, cafe in centre-right, garden at right, pedestrian foreground, no baked people/trains, no text or UI. Generated originals remain in the generation workspace; the repository contains optimized WebP runtime assets.

The living map, illustrated section headers, lesson illustrations, journey cards and adventure-world scenery select these dedicated assets. Headers use different focal crops by section. Scenery selection is independent of companion reward art, preserving existing earned keepsakes. The original four language worlds retain their routes and scenery.

New rolling stock uses separately configured paint, band, carriage length/count and straight routes aligned to visible procedural rails. People use shaded articulated CSS figures with independent walking cadence, depth and shadows. Headers have matching lightweight train/person motion. Scenery is stationary, and map motion unlocks at the existing final restoration phase. Pause, reduced motion and hidden/offscreen train rendering retain the existing controls. Shared cloud graphics are decorative isolated sprites. New train fallback rendering uses the selected country's colours, without a foreign train cutout.

Verification includes unique asset hashes, registered file integrity, per-language rendering, train projection onto rails, reward identity, production build, and Chromium/WebKit mobile checks for loaded country artwork, people motion and reduced motion.
