# Light and Standard lesson modes

Light is an optional guided practice layer for the existing Learn curriculum. Its selector is independent of Photo/Illustration appearance. Standard remains the default, with its original content, randomization, grading, drafts, completion thresholds and unlocks.

All 752 regular current lessons across ten learning languages have two to four activities. Vocabulary, expressions, character meanings and authored examples use model-first observation followed by two-choice recognition or tappable phrase reconstruction. Multi-sentence models without a paired meaning are shortened only at an authored sentence boundary. Native text, graphemes and audio locales are preserved. Korean Hangul composition formulas remain native content. Video lessons retain their original recording and timestamped prompts, with two choices and optional explanatory support. A course's CEFR band does not change.

Checkpoint, summary/placement assessments and externally graded exclusive courses retain Standard. Light completion never writes a Standard practice attempt or draft, grants mastery, unlocks a chapter/companion reward, or changes an assessment result. It records guided activity and active study time. Light history is available from Learn and Learning Memory in both appearances.

Authenticated learner sessions use `/api/learning/light/:lesson` (GET/PUT), with the learner's own history at `/api/learning/light` (GET). The additive `light_learning_sessions` table preserves each session separately, retains immutable completions and cascades only with account deletion. Server validation derives activities from the canonical lesson, validates submitted steps and uses revision checks to reject stale writes. It accepts no client score. The existing self-study pause policy covers writes; account/role and request-origin checks remain enforced.

Guests save their Light record on the current device. Mode preference is scoped to account and learning language on that browser. Photo and Illustration share the same session. Saving occurs after each step, on explicit exit and before switching to Standard. A failed save retains the current activity and prevents switching until recovery; Refresh record explicitly reloads the server copy when another tab has changed the session. The latest session resumes with the selected answer, checked feedback and hint use. Earlier completed sessions remain in authenticated history. Standard stays mounted while switching so its current unsent answer survives a round trip. Audio/video stop on switching; hidden content cannot continue recording or count study time.

All new interface copy includes bundled translations for Japanese, Spanish, Portuguese, Chinese, French, Korean, Indonesian, Russian and Arabic. Existing authored meanings/explanations continue using the published-content translation system. Photo uses practical photographs; Illustration uses regional artwork, warm paper surfaces and the learner's selected companion. CSS is scoped to the learner interface; Admin layout and functions are unchanged.

Validation includes all-lesson activity solvability/source registration, multilingual copy and placeholder checks, real disposable-database API tests for all ten languages, account isolation, immutable history, stale-write rejection and no Standard progress side effects. Browser checks cover hints/retries, mode switching with current answers preserved, completion, resume, appearance switching and responsive layouts. No physical iPhone Safari test has been performed.
