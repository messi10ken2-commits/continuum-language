# Independent Light learning

Light is an independent, game-style learning route alongside Standard. Choose the mode in Learn, or switch inside a regular lesson. Photo/Illustration remains an independent appearance choice. Light completion leads to the next Light round; it does not direct learners to Standard.

The route covers all 752 current regular lessons in the ten learning languages and five course bands, organized into 2,489 short rounds. Each round contains five or six actual retrieval questions. Model previews do not count as questions. Rounds mix authored contextual choices, meaning recognition, translation into the learning language, listening and phrase construction. Native solutions are hidden for translation, listening and construction; contextual questions show the authored task instead of a copied answer. Latin single-word letter sorting and all-identical token puzzles are excluded. Hints give a starting word or general guidance; complete models and explanations appear after a correct answer. Longer models use recognition instead of long tile puzzles. Video rounds retain their authored recording, prompt and time window. Character lessons use native glyph audio; Japanese romanized readings are shown as reading support, never synthesized as Japanese words.

Light has its own lesson/round completion, chapter and level completion, locked/available nodes, XP and next-round navigation. Each completed activity contributes ten Light XP once per unique round; replays never multiply progression or XP. Consecutive correct answers provide session-only encouragement. Incorrect choices receive a hint and another try, with no lives/paywall mechanic. Any course band can be selected, so a learner can start at the appropriate level. Existing Standard checkpoints, placement assessments and external/exclusive courses keep their original operation. Light round completion is not a Standard score, CEFR assessment or certification.

Authenticated records use the existing additive `light_learning_sessions` table. V3 changes question composition. V1 and V2 records remain stored, readable in history and accepted under their original validation contracts. V2/V3 completions share the same lesson/round positions: their progress is retained, and XP uses the maximum earned amount per round instead of summing replays or versions. New V3 drafts have their own versioned namespace; old drafts are retained as historical records because their questions differ. GET `/api/learning/light/progress` deduplicates all completed V2/V3 lesson/round pairs independently of the 50-row recent-history limit. Records are account-scoped, completed rows immutable, and unfinished records cannot change version/round. Revision checks protect against stale overwrites. Save failures retain answers and offer retry/explicit refresh. Guests save on the current device. Account deletion retains the existing cascade policy.

The lesson wrapper preserves unfinished Standard answers during mode switching. Light completion never writes `practice_attempts` or `lesson_drafts`, grants Standard mastery, changes Standard chapter unlocking, or changes an assessment result. Active study time continues to be measured. Audio/video stop when switching or leaving a round. Admin code and production configuration are unchanged; all Light styles are scoped to the learner app.

## Audio correction and verification

Light now resolves every language through `languageInfo`, including Spanish `es-ES` instead of the unsupported bare `es`. All actual Light speech targets are explicitly authorized in the public authored-content speech catalog. The new route uses intact authored model text matching existing recordings, avoiding unrecorded sentence fragments. Japanese character reading audio uses native glyph recordings instead of romaji.

The exhaustive speech-handler test serves every one of 4,296 unique text/locale targets and rejects any attempt to use synthesis, a provider cache or a quota fallback. All return nonempty bundled MP3 recordings; bundle-backed recordings with pinned SHA-256 metadata are checked against their declared digest. This includes Spanish `tener razón`. Existing human-recording priority and attribution remain intact. Counts: Spanish 489, English 587, Portuguese 588, Japanese 822, French 273, German 284, Italian 271, Chinese 326, Korean 328, Arabic 328. These are delivery/integrity checks, not a claim that every recording was listened to manually.

New Light interface text has bundled translations for all nine non-English display locales. Existing authored course meanings and descriptions continue to use the platform's translation system. Standard content and its translations are preserved.

## Release verification

Automated checks cover every model/round and next-round destination, all ten routes, deduplicated XP, all nine display translations, all audio targets, actual disposable-database ownership/save/resume/version/round isolation, stale writes, immutable completions, retained legacy records, long history, and unchanged Standard storage. Existing interface-template, platform/lesson localization, Standard progress, sentence audio, course rendering and request-validation checks are also included. Browser checks use a disposable local test database; no production learner records or payments are modified. Physical iPhone/Safari playback has not been tested.

Chapter headings now use scoped, non-sticky blocks with automatic height and wrapping instead of inheriting the global fixed-height sticky header. The Continue button no longer covers chapter headings while scrolling. Question headings are repositioned below the compact toolbar after advancing. Browser checks cover 320/390/768-pixel surfaces, long chapter titles, contextual grammar, non-revealing hints and six-question completion. Physical iPhone/Safari layout remains unverified.
