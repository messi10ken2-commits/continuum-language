# Continuum World Tokyo — 街の見た目の一次改修

2026年11月26日。Phase 2には進まず、既存Phase 1の視覚表現を更新する。基準は公開済み `428528c`。作業ブランチは `codex/continuum-world-tokyo-visuals`。この変更の本番反映は未承認。

## 参考画像の読み取りと今回の変更

添付画像から、歩行者の高さに近い視点、連続した店舗、ガラス越しの空間、舗装の細かな目地、樹木と建築の陰影、前景から遠景までの重なりを参考にした。ゲーム固有のモデル、画像、看板、ロゴは転載していない。

| 対象 | 変更 |
| --- | --- |
| 通り | メートル単位の舗装、点字ブロック、縁石、排水溝、横断歩道、信号、街灯、店頭ボード、幹を支える木枠 |
| 建築 | 店舗の奥まった空間、開口、ガラス、細いサッシ、階のスラブ、テナント看板、屋上設備、前後に配置した遠景ビル |
| 人物 | 成人の頭身、細い衣服とバックパック、靴、顔の小さな部品、肩・肘・股関節・膝の歩行動作 |
| コンパニオン | 会話用バストと低画質の平面ポートレートの流用を終了。選択済み8種類に対応する街専用の軽量な全身3Dと歩行・羽・頭の動作を追加。他画面の既存コンパニオンは変更しない |
| 室内 | 木床／タイル、窓枠と窓外の立体物、実寸の椅子とテーブル、コーヒーマシン、カップ、軽食、商品棚と商品表示、ペンダント照明 |
| カメラとHUD | 視点を低くして人物へ近づける。街を全画面に描画し、操作UIを画面の縁へ重ねる |
| 安定性 | 繰り返す形状はInstancedMeshでまとめる。画質変更時はレンダラを作り直し、位置は保持する。材質、テクスチャ、インスタンス、影、反射のGPU資源を退出時に破棄する |

西側書店の見た目と衝突範囲を一致させた。以前の保存位置が拡張した建物の中に入る場合は、既存の安全位置復帰が適用される。施設ID、既存進捗、DB、Learning Memory、権限、課金、他モードのデータ構造は変更しない。

## 画質の方針

| 画質 | 表現とコスト制御 |
| --- | --- |
| Auto | テクスチャと拡散照明、建築の投影影と接地影、全身コンパニオン。遅いフレームが継続すると内部解像度を段階的に下げ、倍率0.6を下限とする |
| Low | 上記の軽い材質と接地影。内部解像度0.75、リアルタイムの影マップなし |
| Medium | PBR材質、バンプ、独自に生成した空の反射、1024pxの静的建築の影 |
| High | PBR、より滑らかな曲面、アンチエイリアス、最大2048pxの影、ピクセル比最大1.75 |

Auto/Lowの建築影は、建物の寸法と太陽方向から生成した軽量な投影形状。Medium/Highでは影マップを使用する。動く人物を静的影へ焼き付けず、追従する接地影を使う。夜間の街灯は近い3灯だけを計算する。画質を変更すると必要な材質・形状・反射を作り直す。

道路、舗装、木材にはPoly HavenのCC0写真ベースの1K材質を同梱する。出典・取得URL・SHA-256は `public/world-tokyo/materials/SOURCES.md` に記録した。原本3枚の合計は約2.22MB。実行時は自分の配信元だけから取得し、外部サイトへは接続しない。読込失敗時は独自のCanvas材質へ戻る。その他のコンクリート、金属、樹皮、葉、布、毛は独自の決定論的Canvas描画。Normal/Roughnessの実測マップはまだ導入していない。新しい依存ライブラリや外部モデル生成APIは追加しない。

## 検証

基準のWorld・音声・UI文言テスト13件は変更前に成功。新しい形状・衝突・描画予算・GPU資源破棄・写真素材の整合性・読込中断のテストを含む18件も成功。

```sh
node --test continuum-world-visuals.test.mjs continuum-world-model.test.mjs continuum-world-audio.test.mjs interface-templates.test.mjs
node scripts/qa-continuum-world.mjs
node scripts/qa-continuum-world-visuals.mjs
VITE_CONTINUUM_WORLD_TOKYO_BETA=true npm run build
node scripts/qa-continuum-world-entry.mjs
npm run ios:sync
npm run test:native
```

視覚QAはPC/スマホ幅で昼、夜、2室内を実際に描画し、画像と計測値を保存する。操作QAは通常のPractice画面、徒歩、衝突、実タッチ、画面回転、施設、設定、中断復帰、WebGL復旧、別アカウント、フラグOFFを引き続き扱う。PRのWorldワークフローに全画像とJSONを保存する。確定した最終コミットの結果はPR本文／チェック欄を参照する。

初回のLinux Chromium／SwiftShaderによる観測では、390pxのLowで屋外約27fps、室内約11〜14fps。PC幅の初期Autoは約3〜7fpsとなり、解像度の自動低下と室内の照明削減を追加した。これは途中の非統制測定で、iPhoneの性能や継続30fpsを示すものではない。最終の計測値はワークフロー証跡のJSONを参照する。

## 残っている品質差

この変更はプロシージャルな街の一次改修で、参考画像と同等の完成品質を達成したとは扱わない。

- 人物・動物は独自の軽量形状。高品質なスキニング済み人物、衣服、髪、動物の解剖学的な形状と歩行には追加制作が必要。
- 植生は切り抜きの葉を用いた軽量表現。樹冠の密度、幹の複雑な形状、自然な落ち影には改善余地がある。
- 店舗の種類・密度・固有の内装、建築の汚れ・経年変化・看板の多様さはさらに作り込む必要がある。
- 実在の渋谷を正確に複製した地図ではない。初期仕様どおり東京を参考にした架空街区。
- iPhone実機のFPS、発熱、バッテリー、ピークメモリ、VoiceOverとXcodeのコンパイルは未検証。
- 自由会話、ミッション、NPC記憶、Learning Memoryの統合はPhase 2のまま未実装。

本番へ反映する前に比較画像を確認し、見た目の方向性と実機の負荷を評価する。ベータフラグの既定OFFと、既存のOFF復帰を維持する。
