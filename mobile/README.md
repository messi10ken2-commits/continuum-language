# Continuum mobile staging

This internal Capacitor prototype uses the Railway Staging web service to
exercise the existing Continuum UI and same-origin session handling inside a
native web view. Use staging accounts only. The native project files are
generated by the pinned Capacitor CLI.

## Android

Install Android Studio with JDK 21 and the Android SDK 36, then run from this
directory:

```sh
npm ci
npx --no-install cap add android
npm run sync:android
npx --no-install cap open android
```

After the project is created, run only the sync and open commands as needed.
Run the debug build in Android Studio with an emulator or test device.

## iOS

On a Mac with Xcode 26 or newer:

```sh
npm ci
npx --no-install cap add ios
npm run sync:ios
npx --no-install cap open ios
```

Run the App scheme on an iOS simulator. A physical-device build also requires
signing in Xcode. After the project is created, run only the sync and open
commands as needed.

## First device checks

- Sign in with a staging learner account and reopen the app.
- Open Photo, Illustration and Light Mode. Complete a lesson and confirm that
  the progress is visible when signed into the same staging account on web.
- Check audio playback and exercise navigation. Validate microphone permissions,
  external sign-in and deep links separately before expanding the beta.

The staging app ID is provisional. A store build needs bundled web assets,
a separately configured API and mobile session flow, and sandbox-verified
StoreKit and Play Billing integration. This prototype does not configure native
purchase products or handle store transactions.
